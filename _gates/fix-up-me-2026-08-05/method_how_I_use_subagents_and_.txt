### 2. The gate that exists to catch exactly this is beaten by omission. Self-tested.

`~/.claude/hooks/no-opus-subagent-gate.py` inspects the Workflow **script text** for `model: '...opus...'` (`MODEL_IN_SCRIPT`), and `check()` opens with `m = (model or "").lower(); if not m: return`. Omitting `model:` inherits the session model and the gate sees nothing. I ran both cases:

- explicit `model: claude-opus-5` + mechanical prompt → **deny** (correct)
- workflow script with no `model:` + the same mechanical prompt → **exit 0, empty output, allowed**

That is your anti-superficial test landing on a dispatch control: the gate verifies a **string in a script** instead of the **structural fact of which model the run used**. The structural fact was available , it is written into `wf_45f69e7c-d6b.json` as `defaultModel`. Worse, MODEL_ROUTING.md blesses the bypass in its own text: *"omit `model:` to inherit the session model ONLY for stages that genuinely need orchestrator-grade reasoning."* The unenforceable half of the sentence is the half that got used, 34 times.

### 6. The two changes that follow from the evidence

**a. Make the routing gate structural.** It cannot read `model:` from script text, because the compliant-looking script omits it. It must read the resolved model for the dispatch , the same value the runner already writes as `defaultModel` , and deny a mechanical/build prompt resolving to an opus tier whether the tier was declared or inherited. As written, the gate's pass condition is "do not type the word opus", which is a string, not a fact.

**b. Delete the inherit-by-omission clause from MODEL_ROUTING.md**, or require the stage to name its tier explicitly, including when that tier is the session model. An escape hatch whose condition ("stages that genuinely need orchestrator-grade reasoning") is self-assessed by the dispatcher is not a condition.
