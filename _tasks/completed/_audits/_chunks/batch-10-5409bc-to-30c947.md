## Batch Summary

**Date range:** 2026-03-25 10:37:38 → 2026-03-25 14:50:43 (same day, ~4 hours of work)

**Defining theme:** A single-day "V3 compliance sprint" that swept the entire visible UI — booking flow, auth, global layout, dashboard, profile, and discovery — in 10 consecutive commits. The goal was eliminating "NEVER violations" (scale animations, backdrop-blur in wrong zones, glass in Zone 3/4 contexts) while applying Zone 2/3/4 patterns consistently.

### Components introduced
- `ProfileSectionLabel` (new component within ProfilePage, commit 9)
- `glass-subtle` CSS tier in globals.css (commit 8)
- `font-mono-code` utility (JetBrains Mono, commit 8)

### Components rewritten
- `components/BookingCalendar.tsx` — full Zone 3 port
- `components/booking/ServiceCart.tsx` — icon-inset inputs, eyebrow labels
- `components/booking/GuestBookingForm.tsx` — coral CTA shadow
- `components/booking/PackageRedeemBanner.tsx` — amber tint
- `app/[locale]/auth/login/page.tsx`, `register/page.tsx`, `reset-password/page.tsx`, `components/auth/SignIn.tsx`
- `components/layout/Header.tsx`, `Footer.tsx`, `BottomNav.tsx`
- `components/ui/Toast.tsx`, `Spinner.tsx`, `Skeleton.tsx`, `TrustBadges.tsx`, `GlassModal.tsx`
- `components/SalonCard.tsx`
- `components/dashboard/DashboardLayout.tsx` + 6 dashboard sub-components
- `components/ProfilePage.tsx`, `components/loyalty/StampCard.tsx`
- 13 discovery components

### Components deleted
None — all previously-existing files were modified, not deleted.

### Design tokens added
- `glass-subtle` tier (rgba(255,255,255,0.92) + blur(12px))
- Dark mode glass variants (`.dark .glass`, `.dark .glass-strong`, `.dark .glass-subtle`)
- `font-mono-code` / JetBrains Mono font

### Design tokens removed / renamed
- `rounded-button` (8px) — REMOVED from tailwind.config.js (NEVER violation)
- `rounded-blob` — REMOVED from tailwind.config.js (NEVER violation)
- `shadow-glass` — RENAMED to `shadow-surface` across all files
- `backdrop-blur-glass` — RENAMED to `backdrop-blur-panel`

### Animation patterns changed
- `stampBounce` / `photoUpload` / `cardPopIn`: scale-based → opacity + translateY only (NEVER violation fix)
- `pressAnimation`: scale 0.95 → 0.98 (V3 max 2% rule)
- `containerVariants` stagger: 200ms → 80ms

### Patterns adopted
- Eyebrow labels: 9px `font-heading font-bold uppercase tracking-[.18em]` above sections
- Zone 3 inputs: `py-3.5` padding, icon-inset pattern
- Coral CTA shadow: `box-shadow: 0 2px 4px rgba(232,98,74,.30), 0 6px 20px rgba(232,98,74,.20)`
- 12px radius (`rounded-[12px]`) for cards in Zone 3
- `font-heading font-bold uppercase` on all CTA button text

### Patterns rejected
- Glass + backdrop-blur in Zone 3/4 (BottomNav, Toast, summary strips)
- Scale spring animations on entrance/exit
- `shadow-glass` token name (replaced by `shadow-surface`)
- `rounded-button` (8px pills) and `rounded-blob` custom tokens
