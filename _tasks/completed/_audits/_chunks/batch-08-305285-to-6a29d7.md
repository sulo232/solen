## Batch Summary

### Date range
2026-03-25 00:02 – 10:07 (all within a single 10-hour session)

### Defining theme
**R31 homepage editorial redesign + R33 warm token cleanup.** The batch opens with infrastructure work (SEO JSON-LD, i18n cleanup, accessibility) and closes with a rapid-fire visual overhaul of the homepage: hero split layout, gradient category tiles, plum Last Minute section, and global warm shadow system.

### Components introduced
- `components/ui/HeroVisualCard.tsx` — new floating salon preview card for hero right column (alive at HEAD)
- `lib/seo.ts` — new SEO helper functions (`generateCategoryListSchema`, `generateWebsiteSchema`, `buildAlternates`) (alive at HEAD)

### Components rewritten
- `components/HomePage.tsx` — hero (center → 2-col editorial), category tiles (icon cards → gradient squares), Last Minute (coral-subtle → plum dark)
- `components/ui/GlassModal.tsx` — added `useFocusTrap` hook + `aria-modal`

### Components updated (non-rewrite)
- `components/SalonCard.tsx` — blur placeholder
- `components/dashboard/DashboardLayout.tsx` — i18n labels
- `app/globals.css` — input focus ring + universal reduced-motion
- `tailwind.config.js` — warm shadow alias remapping

### Design tokens added
- Warm shadow values replacing cold `rgba(0,0,0,...)` in `card`/`glass` aliases
- `inset 0 1px 2px rgba(26,18,9,.06)` added to `pressed` shadow
- Coral focus box-shadow ring for inputs: `0 0 0 3px #FAECE7`

### Design tokens removed / replaced
- Cold `rgba(0,0,0,0.08/.12/.06/.10)` shadow aliases removed (migrated to warm ink `rgba(26,18,9,...)`)
- Lucide icons Scissors, Droplets, Palette, Zap, ScissorsLineDashed removed from category tile definitions

### Patterns adopted
- Editorial 2-column hero grid (`lg:grid-cols-2`) with Bebas Neue display type
- Gradient-fill tiles replacing icon+bg-color cards
- Dark section with decorative blobs (`bg-s-plum`) for urgency sections
- Universal `prefers-reduced-motion` via `*` selector (replaces per-class list)
- Box-shadow focus rings on inputs (more faithful to border-radius than outline)

### Patterns rejected
- Center-aligned hero (replaced by editorial split)
- Icon-based category navigation (replaced by gradient photo-ready tiles)
- Per-class reduced-motion overrides (replaced by universal `*` rule)
- Cold black-shadow card/glass tokens

### Lost patterns (not at HEAD)
- Skip-to-content link added in commit 4 (`a6e211c`) appears to have been lost in a subsequent layout rewrite
- Plum dark Last Minute section from commit 9 (`7773547`) not present at HEAD (later rework reverted it to a different section style)
