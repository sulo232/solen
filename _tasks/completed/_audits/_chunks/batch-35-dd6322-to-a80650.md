## Summary

**Date range:** 2026-03-30 09:34 – 10:45 (single session, ~71 minutes)

**Defining theme:** Intensive GuidedSearch polish sprint — the entire batch is a rapid sequential refinement of the search UX flow, mixed with supporting bug fixes (dead links, missing API routes, missing deps).

### Components introduced
- `components/search/SearchCriteriaChips.tsx` — new (commit 10)

### Components significantly rewritten
- `components/ui/GuidedSearch.tsx` — touched by 6 of 10 commits; evolves from a list-style category flow → 2-col card grid → scroll-driven collapsible Airbnb-style pill

### Components with minor changes
- `components/layout/Header.tsx` — compact pill added to sticky nav (commit 2), dead links fixed (commit 5)
- `components/auth/TosPrompt.tsx`, `components/dashboard/GoLiveGate.tsx` — raw `<a>` → `<Link>` (commit 5)
- `components/CategoryPage.tsx`, `components/search/SplitView.tsx` — SearchCriteriaChips wired in (commit 10)

### Components deleted
- Barrel exports removed: `PriceSlider`, `GlassCard`, `AnimatedButton`, `SearchBar`, `SocialProofStrip`, `BottomNav` (from `components/index.ts` only — underlying files may still exist)

### Design tokens added / changed
- `rounded-pill` used on SearchCriteriaChips (aligned with spec)
- `rounded-card` used on 2-col category cards (commit 8)
- Coral active state (`border-s-coral`, `bg-s-coral/[0.04]`) applied to category cards
- Compact pill uses coral icon + `·` separator — consistent with design spec
- Tappable step tabs use coral underline indicator via Framer Motion `layoutId`
- Dark mode variants maintained throughout (`dark:bg-s-dm-raised`, `dark:text-s-dm-text`)
- Old `border-[#F5F5F5]` hardcoded border on list-style categories removed (LOST, commit 8)

### API routes added
- `GET /api/staff` (commit 4, alive at HEAD — many more staff routes exist)
- `GET /api/slots/last-minute` (alive)
- `GET /api/salons/by-slug/[slug]` (alive)
- `DELETE /api/salon/closures/[id]` (alive)

### i18n
- `orSearch` key added to de/en/fr/it (commit 8)
- `ui.search.*` namespace expanded with chip labels + `removeFilter` (commit 10)

### Patterns adopted
- Scroll-driven Airbnb-style pill collapse (scrollY > 80px threshold)
- Framer Motion `AnimatePresence mode=wait` for pill cross-fade
- `layoutId` for animated coral tab underline
- 2-col card grid with coral active border for category selection
- Removable URL-param chips on results page

### Patterns rejected / lost
- List-style category rows with top border (`border-t border-[#F5F5F5]`) — replaced by card grid (commit 8)
- Emoji category icons — replaced by custom SVG + Lucide (commit 1)
- Non-interactive animated progress dots — replaced by tappable tabs (commit 7)
