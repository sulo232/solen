**Defining theme:** Two parallel workstreams compressed into one day: (A) full FilterBar migration to replace the legacy `SearchFilterBar` architecture across all search/category/last-minute pages, and (B) bootstrap of a beauty profile subcomponent system with edit persistence, followed by a dashboard i18n wiring pass.

### Design Tokens Removed

### Patterns Adopted
- Grouped `FilterBar` + `SearchAutocomplete` replacing monolithic `SearchFilterBar` across all listing pages
- `useTranslations()` from next-intl replacing inline translation objects in dashboard components
- Profile subcomponent decomposition (hero / card / highlights / tabs / grid)

### Patterns Rejected / Concerns
- **Custom SVG icons (`beauty-icons.tsx`):** Design spec mandates `lucide-react` outlined icons. This 222-line custom SVG library introduces 15+ custom icons for hair textures and beauty attributes not in lucide. This is a direct conflict with the icon lock in `SOLEN_DESIGN.md`.
- **Dark mode glass tokens (C1):** Q16 lock retired dark mode; `--glass-bg` dark variants added here may be orphaned dead tokens. Verify no dark mode CSS is consumed at HEAD.
- **Wide footprint on C3:** `CLAUDE.md` was modified +125 lines as a side-effect of a FilterBar migration commit — unusual and potentially problematic.
