What changes if you say "go" on the polish

Same V3 brand, V3 fonts, V3 categories, V3 pill rule, V3 atmosphere recipe, V3 color philosophy, V3 voice. Only the §5b depth system + §1 hover gradient + a few §19 / §20 specific bits get modernized.

Token / pattern Current spec (left) Modern proposal (right) Why
§5b L1 raised inset 0 1px 0 rgba(255,255,255,.6) + 0 1px 1px rgba(26,18,9,.04) 0 1px 2px rgba(0,0,0,.04) only Drops Web 2.0 inset highlight
§5b L2 surface same inset + 0 2px 8px 0 2px 12px rgba(0,0,0,.04) Single soft shadow
§5b L3 elevated 3 stacked shadows + inset 0 4px 16px rgba(0,0,0,.06) on hover only Flat resting state, lift on hover
§5b L4 overlay blur(12px) saturate(1.4) blur(16px) saturate(1) Drops iOS 7 vibrance pump
§5b L5 accent glow tinted brand-color shadow Removed entirely — modern UIs don't glow CTAs "Lift, never glow"
§1 hover gradient linear-gradient(180deg, #0A6873 0%, #043338 100%) Flat #043338, hover → flat #0A6873 via background transition Linear/Stripe button style
§5b card surface linear-gradient(180deg, #fff, #FDFAF5) Flat #FFFFFF Drops "waxed paper" sheen
§5g atmosphere wash opacity 0.78 / 0.72 / 0.32 / 0.28 0.40 / 0.40 / 0.10 / 0.10 Less screensaver, more weather behind glass
§19 city tiles Brand-teal gradient + line icons + white text on all 3 Flat per-city tint (brand-subtle / warm bone / sand) + dark text Restores city differentiation; flat reads modern
§20 B2B card Peach gradient + 2 blurred blobs + 3 stacked shadows + inset Flat brand-subtle bg + hairline border + flat CTA Drops 2018 marketing-site tropes
