§25.2 · §25.3 · HEADER + CRUMBS

Sticky header w glass blur

Header sticks always (per §12). Below it: breadcrumbs `solen / Basel / Coiffeur` give SEO + nav hierarchy. Bell icon shows brand-orange dot when notifications exist.

  • Header reuses §12 minimal pattern w city pill
  • Back arrow → history.back() w fallback to /[city]
  • Crumbs rendered as <nav aria-label="breadcrumb"> + JSON-LD BreadcrumbList in <head>
  • Crumb separator / at 22% opacity ink-1, 1px margin
  • Current item (Coiffeur) is <span aria-current="page"> not a link
§25.4 · TITLE BLOCK

h1 + sub w pulse dot

Bricolage Grotesque 700 28px h1. Sub-text shows real-time count w green pulse dot. When filters active: dot disappears, sub becomes "[N] Salons · gefiltert".

  • h1 size clamp(24px, 5vw, 32px), line-height 1, letter-spacing -0.028em
  • Pulse dot is 5px green #16A34A, 1.6s infinite per §5c.7
  • Count refetches every 60s OR on visibility change (real-time)
  • Plural handled: 1 Salon (singular) vs 23 Salons (plural)
  • Zero results: shows "0 Salons · gefiltert · Filter zurücksetzen" inline link in brand-orange
§25.5 · FILTER PILLS

4 pills · scrollable

Default state: Alle active, Heute frei quick toggle, Sortieren ▾ opens sheet, Filter opens 3-cat sheet. When filters active: count badge appears on Filter pill (e.g. "Filter (3)").

  • Pills are linear-gradient(180deg, #fff, #FDFAF5) w peach shadow
  • Active state: ink-1 bg, white text, inset highlight
  • Inter Tight 600 12px, padding 8×13px, radius pill
  • Tap target ≥44px even tho visual is smaller (per §11)
  • Scrolls horizontally on overflow, scrollbar hidden
§25.6 · SORTIEREN SHEET

Bottom sheet w 5 radio options

Tap "Sortieren ▾" → bottom sheet w dimmed backdrop, swipe-down to dismiss. 5 options total.

  • Empfohlen (default) — server smart-mix algorithm
  • Beste Bewertung — rating descending
  • Heute am frühesten frei — earliest slot today
  • Preis · niedrig zuerst — lowest "ab CHF X" first
  • Nähe — distance ascending (requires geo)
  • Radio circles: 18×18px, 2px ink-1 .25 border, brand-orange when selected
  • Sheet z-index var(--z-modal) per §8 — uses React portal
§25.7 · FILTER SHEET

3 categories · live count CTA

Tap "Filter" → bottom sheet w 3 categories: Verfügbarkeit, Service-Typ, Preisspanne. Live-counted CTA at bottom updates w each toggle.

  • Verfügbarkeit: pill multi-select — Heute frei / Sofort frei / Diese Woche / Wochenende / Abends nach 18:00
  • Service-Typ (varies by category): Coiffeur = Damen / Herren / Kinder / Schnitt / Föhnen / Coloration / Highlights
  • Preisspanne: dual-thumb slider CHF 0–500
  • CTA copy: "Alle 23 Salons anzeigen" → "14 Salons anzeigen →" (live, 200ms debounce)
  • Zero matches: CTA disabled "Keine Treffer", ink-3 bg
  • Top-right "Zurücksetzen" link clears all filters but doesn't dismiss
  • Swipe down dismisses w/o applying (cancel)
§25.8 · GRID

Infinite scroll · 2/3/4 cols

Mobile 2 cols, tablet 3, desktop 4. Loads 12 cards initial, fetches next 12 within 400px of bottom. Skeleton shimmer L→R during fetch.

  • Cards use service variant per §16.5 — line 2 = "Schnitt + Föhnen · ab CHF 85"
  • Photo aspect 1:1, 14px radius, peach soft shadow
  • Badge top-left: "Heute frei" (green dot) or "Sofort frei" (orange dot)
  • Heart top-right: outline → filled love-red on save (logged-in)
  • Logged-out heart tap → login modal w return-to-card
  • Photo fallback: category-color tile w salon initials (per §16.7b)
  • End of list: separator + italic "Du hast alle 23 Salons gesehen"
§25.9 · EMPTY STATES

3 conditions · 3 responses

Each empty state respects user intent + offers a path forward. Never dead-ends.

  • Zero filter matches: 88×88px peach circle illustration → "Keine Salons mit diesen Filtern" → "Filter zurücksetzen" CTA → cross-city secondary link
  • Category coming soon (e.g. /bern/makeup): "Makeup kommt bald nach Bern" → email waitlist CTA → cross-city secondary
  • API error: inline retry first, escalates to full empty state after 5 retries
§25.10 · STICKY SCROLL

Pills sticky after h1 scrolls out

When scrollY ≥ 120px, filter pills row becomes position: sticky; top: 48px w glass blur bg. User can refine mid-scroll without scrolling back up.

  • Header z-index var(--z-sticky)
  • Sticky pills z-index one below header
  • Both gain backdrop-filter: blur(12px) saturate(1.4)
  • Transition 200ms var(--ease-snap)
  • Crumbs + h1 + sub scroll naturally (NOT sticky)
§25.11 · CROSS-LINK FOOTER

2 SEO link blocks

Lives between end-of-grid and main footer. Pure internal-link surface — google rewards link density. Auto-scales w new cities/categories.

  • Block 1: "Andere Kategorien in [City]" — 5 sibling categories
  • Block 2: "[Category] in anderen Städten" — same category in other v1 cities
  • Each link → /[city]/[category]
  • Hover state: brand-orange #E8742A
  • Container bg linear-gradient(180deg, #FBF8F3 0%, #F5EFE6 100%)
  • Wraps as new categories/cities are added
§25.12 · META + SEO

Server-side dynamic meta + JSON-LD

Every value generated server-side from city + category data. Numbers in meta description trigger google rich results.

  • <title>: "Coiffeur Salons in Basel buchen — Solen" (60 char max)
  • <meta description>: includes count + min price + today-free count
  • JSON-LD BreadcrumbList + ItemList of HairSalon
  • hreflang: DE (default no prefix) / EN / FR / IT
  • og:image dynamically gen 1200×630 per page
  • canonical even when filtered (filters don't get own SEO weight)
§25.13 · URL PARAMS

Filter persistence via query strings

Filters sync to URL for shareability + back-button. Use router.replace() so filter changes don't pollute history.

  • ?heute=1 — Heute frei toggle
  • ?service=damen,coloration — multi-select comma-separated
  • ?preis=50-200 — price range
  • ?sort=rating — non-default sort
  • Combined: /basel/coiffeur?heute=1&service=damen&sort=slot
  • Invalid params silently ignored
§25.16 · DO NOT

Things v1 explicitly skips

Common mistakes to avoid. Each one was considered and explicitly deferred or rejected.

  • NO map view in v1 — defer to ?view=map in v2
  • NO Bewertung/Distanz/Sprachen filters in v1
  • NO "Featured" promoted salons mixed into grid (no paid ranking v1)
  • NO pre-loading all salons — infinite scroll only
  • NO auto-detect Heute frei from time of day — explicit user action
  • NO save filter selections across sessions — URL-scoped only
  • NO different sort options for logged-in vs out — show all 5 always
