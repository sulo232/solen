The rule
  • Deep page (salon, confirmation, booking, profile sub-pages, help article) → left slot = Back (router.back(), falls back to a sensible parent). No breadcrumb on mobile.

  • Bell + menu unchanged. Desktop keeps breadcrumbs (room for them).
