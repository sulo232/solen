Dashboard mobil — alle 13 Owner-Seiten (im freigegebenen Skin)

Jede Seite des Owner-Dashboards (PC-Rail-Set), für Mobile neu gebaut: gleiche Features wie die PC-Version, aber touch-first (Karten statt Tabellen, Scroll-Pills, Bottom-Sheets, 44px-Tap-Targets). Skin = freigegebene Übersicht: weisse Seite, 16px-Karten mit Haarlinien, runde farbige Avatare, ink-Primary, blaue Aktiv-States, semantische Pills, blanke lucide-Icons, Salonname statt „Solen". English annotations under each phone explain what desktop feature is preserved + how it is adapted for touch.
