Anti-patterns §F.4.8 · banned

Anti-patterns

What Solen toasts do not do.

Banned
Toasts replacing form-field error messages
Field errors use <FieldHelper tone="error"> anchored to the field per §F.1.0. Toasts are for non-anchored feedback only.
Banned
Modals masquerading as toasts
If user MUST respond, it's a modal. If they don't have to, it's a toast. Don't blur the line.
Banned
Two action buttons on a toast
At most 1 action + dismiss. Two actions = modal. Toasts are aside, not focus.
Banned
Auto-dismissing errors
Errors stick until user acts. Override only for informational errors ("offline mode aktiviert" — not blocking).
Banned
4+ toasts visible
Max 3 visible. 4th+ queues. Higher visual stack = noise.
Banned
Top-of-screen toasts
Bottom is locked v1 position. Matches mobile thumb position; doesn't block primary content.
Banned
Brand-teal as success color
Per §3 semantic system: #16A34A. Brand-teal is for navigation + CTAs.
Banned
Form inputs / multi-step controls inside toasts
That's a modal. Toasts are read-and-dismiss aside notifications, not focus surfaces.
