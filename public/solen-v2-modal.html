Modal primitive

Centered overlay for confirmations, login flows, focused single-task interactions, and content that must steal user attention until resolved. Distinct from sheet (§F.3) — modals work identically on mobile and desktop. They never auto-dismiss and never stack.

Anatomy §F.2.0 · backdrop + surface

Anatomy

Backdrop dims (warm-ink rgba(26,18,9,.40), never pure black) + blurs (4px, tasteful). Surface centered, white #FFFFFF, radius 16px, elevation-3 warm-tinted shadow. Header / Body / Footer always in that vertical order; footer sticky at bottom when body scrolls.

State matrix §F.2.0b · 4 phases

State matrix

Modals don't bounce or spring — they're functional confirmations, not playful reveals. Both entry and exit use ease-snap (cubic-bezier(.4,0,.2,1)). Reduced-motion: collapse to opacity-only, 100ms duration.

01 · closed
Not rendered
No DOM nodes. Trigger element retains focus.
02 · opening
Backdrop fades 0→1, modal scales 0.95→1
200ms backdrop · 250ms modal · ease-snap. Body scroll locked.
03 · open
Static · interactive
Backdrop at 0.40 dim, modal at scale 1. Focus trapped within.
04 · dismissing
Modal scales 1→0.95, fades to 0
150ms · ease-snap. Then unmount + restore focus to trigger.
Anti-patterns §F.2.10 · banned

Anti-patterns

What Solen modals do not do. Each ban exists because the pattern fights either accessibility, the §F.2 single-task focus principle, or the V2-D15-4 motion discipline.

Banned
Nested modals (modal-on-modal)
Open ONE modal at a time. For "discard unsaved changes?" flows, swap the SAME modal's body content. Stacking creates dismissal-order ambiguity and breaks focus traps.
Banned
Auto-dismiss timeouts
Modals never auto-close. User dismisses explicitly via X / Escape / backdrop click. Auto-dismiss = §F.4 toast — different primitive, different semantics.
Banned
Pure black backdrop
Per §4 anti-pattern: never rgba(0,0,0,X). Always warm-ink tint rgba(26,18,9,0.40) + 4px blur.
Banned
Hidden close button until hover
Per §11 hit-target baseline: close X always visible. Hover-revealed dismissal fails on touch + violates discoverability.
Banned
Modals as marketing prompts
Modals interrupt and demand action. Reserve for must-resolve interactions. Use §F.4 toasts for non-actionable info, pages for marketing content.
Banned
Disable escape + backdrop-click + hide close X
User must always have AT LEAST ONE explicit way to exit. Trapping users in a modal violates §11 + §24b.1 keyboard-nav baselines.
Banned
Auto-morph to bottom sheet on mobile
Sheets are §F.3, distinct primitive. Confirmation modals stay centered everywhere — sheet semantics (swipe down, snap heights) don't fit confirmation UX.
Banned
Italic anywhere in modal
Per V2-D15: italic banned across all UI. Title, body, button labels — all upright Avant Garde Gothic.
