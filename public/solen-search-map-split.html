Why "C + map" works: list-beside-map vs grid-beside-map (desktop, map open)

Your search already has the map split (grid-cols-[1fr_minmax(380px,46%)]). The question is what fills the left column when the map is open. A list row maps 1:1 to a pin and uses the narrow column well. A grid crams tiny squares. Same card family either way; list rows also have room for a next-slot line.
