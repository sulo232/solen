Eligibility categories (REFUND_APPEAL_PLAN §11, Lane B): Fast-track salon-cancelled / no-showed → full · wrong amount / double charge → difference (recommended, still confirmed). Discretionary service-quality / not-as-described → salon decides, customer can escalate. Policy cancellation inside the window → policy refund only. Not eligible change of mind / outside the window.
Statuses: New → In review → Approved (full / partial) / Rejected → Escalated to Solen → Refunded. Every state writes to the case timeline. Review-first: nothing auto-approves — money moves only on explicit confirmation; the eligibility flag is a hint, never an action. Money stored in Rappen, shown as CHF. Data model extends booking_disputes (no new table) per council §10b.1.
