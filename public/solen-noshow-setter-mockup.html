Phase C — No-Show-Gebühr setter · v2 (color = the message)

You said v1 was too monochrome. Fix isn't random colour — it's the semantic one: a no-show fee is a charge, so it uses the surcharge orange (#EA580C) the system reserves for money-out, never flat ink. A charging option (Pauschale / Prozentual) lights up orange = "this bills the customer's card"; „Keine" stays calm (green = nothing charged). The amount rides on the selected card and in a pale-orange value field. Selection elsewhere in the app stays blue — orange here means money.
