Solen color system — rebuild via UX Tools principles

4 color families total. One brand (with full scale). One restricted-use navy. One neutral ink scale. 3 semantic colors. No more "add a new chromatic color for every UI question" loop.

Principles applied (from the video):

  1. One primary color. Build a 9-shade scale from it. Use shades, not new hues, when you need variants.
  2. Semantic colors are NOT brand colors. Success / warning / danger live in their own bucket so they can do their universal job everywhere without competing with brand identity.
  3. Max ~10 shades per family. If you can't pick a shade from the scale, the question is wrong — don't invent.
  4. Accessibility: body text on white = ink-700+ minimum (passes WCAG AA at 4.5:1).
  5. Test in context — not in swatches, in the actual UI.

Counting colors on this page:
orange-500 (banner) · orange-500 ("Schöner") · orange-500 (logo dot) · orange-600 (button) · orange-100 (tag bg) · orange-700 (tag text) · orange-200 (trust accent) · navy-900 (trust band) · success (Heute pill) · danger (heart + sale) · ink scale (text)

What this fixes:

1. The button question dies. Primary CTA = orange-600 (a shade of the brand). No new color needed. No teal, no purple, no jade, no chartreuse, no gold. The scale already has the answer.

2. The "navy everywhere" risk is addressed — navy is now LIMITED to a 3-stop scale, with explicit guidance that it appears scarcely (B2B band only).

3. One red, not two. Heart-pink + urgency-red merge into a single danger semantic. Reduces semantic load. The saved heart is now the same red as a sale tag — that's fine because both signal "loud emotional state."

4. Cream is officially absorbed. orange-50 / 100 covers what cream was doing (editorial section bg, ultra-soft surfaces). No separate token needed.

5. No more "let's add a new color" loop. The rule is: if your design needs a color, pick from this system. If nothing in the system fits, the design is asking the wrong question.

Honest pushback: the "heart and sale tag both use red" choice is debatable. Some teams keep heart-pink #FF3366 separate because pink-heart is a specific cultural pattern (Instagram, Twitter, etc). Acceptable to keep heart as a 4th semantic. Adds 1 more color but preserves the pattern. Your call.
