§3 — Accent Application Rules

Color: narrow blue to system feedback only

Measured: Uber gates #276EF1 (Solen's exact s-accent) on :focus-visible rings + <Spinner /> only. No CTAs, no body links, no eyebrows, no tabs, no toggles, no map pins, no decorative spans. Solen currently paints accent on ~8-12% of pixels. Uber paints it on ~1-3%.

✓ ALLOWED — :focus-visible ring around any focusable element. Recipe: box-shadow: 0 0 0 2px white inset, 0 0 0 2px #276EF1 (double-ring) OR outline: 3px solid #276EF1; outline-offset: 1px for text links.
✓ ALLOWED — Loading spinner arc. Track grey, animated arc #276EF1. Matches Uber's Base Web <Spinner />.
✓ ALLOWED — Form input focus state (border + ring). Same recipe as focus-visible.
✗ FORBIDDEN — Eyebrow text. Current text-s-accent uppercase eyebrows → downgrade to text-s-ink-3.
✗ FORBIDDEN — Link text. Current text-s-accent links → text-s-ink underline.
✗ FORBIDDEN — Decorative icons / dots / hero accent spans. → ink or black.
✗ FORBIDDEN — Text on pale-blue bg pairing (the "vibrating" pattern). Either flip bg to white OR flip text to ink. Never both blue.
✗ FORBIDDEN — Step circles, checkmarks, dots. Move to s-ink or s-success (semantic).
