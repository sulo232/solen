Bottom sheet primitive

Mobile-only bottom-anchored overlay for filters, sort, share, look-detail. Slides up from the bottom edge with a drag handle. On desktop (≥ 768px), Sheet falls back to §F.2 Modal via useResponsiveOverlay(). v1: single fixed height (75vh default, auto / full variants). v2: multi-snap + swipe gesture.

State matrix §F.3.0b · 4 phases

State matrix

Sheet uses ease-glide for entry (600ms) — long-distance smooth from translateY(100%) to translateY(0). Exit uses ease-snap (200ms). Reduced-motion: opacity-only fade, 100ms.

01 · closed
Not rendered
No DOM nodes. Trigger retains focus.
02 · opening
translateY(100%) → translateY(0)
600ms ease-glide. Backdrop fades 0→1 over 300ms. Body scroll locked.
03 · open
Static · interactive
Backdrop at 0.40 dim. Sheet at translateY(0). Focus trapped within.
04 · dismissing
translateY(0) → translateY(100%)
200ms ease-snap. Backdrop fades 1→0 over 200ms. Then unmount + restore focus.
Anti-patterns §F.3.9 · banned

Anti-patterns

What Solen sheets do not do.

Banned
Sheet on desktop
Full-width bottom-anchored on a 1440px screen reads as banner ad. Use useResponsiveOverlay() or split components manually.
Banned
Multiple sheets stacked
Open ONE sheet at a time. Same rule as §F.2 modal — stacking creates dismissal-order ambiguity and breaks focus traps.
Banned
Bottom corners rounded
Sheet flush-bottoms to viewport edge. Top-only radius makes the "this slides up from below" affordance clear.
Banned
Pure black backdrop
Per §4 anti-pattern: never rgba(0,0,0,X). Always warm-ink tint rgba(26,18,9,0.40) + 4px blur. Note: §25.6 spec text references stale pure-black hex — when implemented via §F.3, this primitive's warm-ink prevails.
Banned
Sheet without sticky bottom CTA when there's a confirm action
The sticky CTA is the sheet's defining UX vs modal. Read-only sheets (look-detail) can omit the CTA, but action-required sheets MUST have it sticky bottom.
Accepted compromise
Drag handle without functional swipe (in v1)
v1 ships visual handle only — swipe gesture deferred to v2. Document, don't fight. Users still expect handle visually (familiar from iOS/Material).
Banned
Hidden close X
Per §11 hit-target baseline: close X always visible. Even with swipe-down (v2), X remains the explicit fallback.
Banned
Italic anywhere in sheet
Per V2-D15: italic banned across all UI. Title, body, button labels — all upright Avant Garde Gothic.
