Guest booking lookup

For people who booked as a guest (no account). They enter their order number to find a booking — but the order number alone never grants access. We email a secure access link; the link is what opens the booking, where they can then request a refund or report a problem. Structure follows Treatwell / Fresha "find your booking"; aesthetic follows the Solen system (ink CTAs, Uber-blue only on input focus, Inter Tight + Inter + JetBrains Mono).

Auth model: order number = find, emailed token link = access (per plan §10b.7) Rate-limited lookup + resend One entry point on the booking: Report a problem / Request a refund (§10b.2) Amounts in CHF at the UI boundary, integer Rappen underneath
