What Lottie actually is (mechanically)

Lottie is a JSON file. Nothing more. It describes vector shapes + a timeline of keyframes (what moves, when, how). At runtime, a small JavaScript library called lottie-web reads the JSON, builds DOM/SVG/Canvas elements, and animates them by interpolating between keyframes — like a player rendering an animated GIF, but with vector math so it scales infinitely.

It came from Airbnb in 2017. The author flow assumes you have After Effects + a free plugin called bodymovin, which exports a composition's vector layers as JSON. That's the "hard" part of Lottie — you need After Effects + animation chops. Using a Lottie someone else made is trivial.

Solen-relevant tradeoff: the lamp toggle in the reel could be (a) a Lottie JSON, (b) inline SVG + CSS animation, or (c) Framer Motion. Same visual result. Lottie wins when the animation is complex (>10 moving parts), needs to be the SAME across web/iOS/Android (one JSON file, identical playback). SVG+CSS wins for simple state toggles at small sizes (smaller payload, no library).

SVG+CSS vs Lottie — when each wins

DimensionSVG + CSS / Framer MotionLottie (JSON)
File size 1–5 KB inline 30–300 KB JSON + ~50 KB lottie-web lib
Authoring Code in CSS/SVG paths (I can do this) After Effects + bodymovin plugin (I can't author from scratch)
Sourcing ready-made Phosphor, Heroicons, Lucide all free LottieFiles 200k+ free + paid
Visual ceiling Good for state toggles, simple loops, hover effects Best for complex multi-part choreography (e.g. confetti, characters)
Cross-platform consistency Same code, may render slightly different per browser One JSON identical on web/iOS/Android/Watch
Runtime cost Native browser, very cheap JS thread renders each frame, can jank on low-end devices
Best size to use at Any (icons + UI states + tiny pieces) 60px+ — motion needs pixels to register

For Solen, here's the honest call

Use SVG+CSS for the Für dich tile icons. They're 38px. The motion in a Lottie at that size is invisible to users. Inline SVG with subtle CSS transitions (the icon scales 1.05 on hover, color shifts to mint green) gives you all the polish without the 150KB payload.

Save Lottie for the moments that EARN it: onboarding success animations (90px+), empty states (a 200px illustration of "no bookings yet" that dances), the booking-confirmed checkmark explosion. THOSE are where Lottie's payload pays off — they're rare, big, and memorable.
