CTA + hierarchy: current vs Uber-aligned

The "JETZT ENTDECKEN" CTA on /warum-solen reads cheap because Solen uses uppercase + small (12px) + tracked + Geist Sans on PRIMARY actions — a 2018-era SaaS template trope. Uber abandoned this years ago. They use sentence case + body size + medium weight for CTAs. The data: 19 instances of the same uppercase-12px-black-pill pattern across the codebase, 20 distinct letter-spacing values in use, 733 uppercase usages total.

Diagnosis: the "cheap" feel is not the FONT — Geist Sans is fine. It's the PATTERN: uppercase + small + tracked + heavyweight, applied to primary actions. That combo screams "Webflow template" because it was the 2018-2020 default for SaaS landing pages. Uber, Stripe (recent rebrand), Linear, Vercel — all dropped it. They use sentence case + size + weight + color as hierarchy, not uppercase tracking.

Why we have it: Inter Tight era (pre-V3-D317) used uppercase as a "heading-feel at small size" trick. V3-D317 swapped to Geist single-family but kept the pattern. Geist was designed for code labels + UI chips — at uppercase + small + tracked it reads as a TAG, not an ACTION. That's the dissonance.

Recommend B→full Uber alignment. Drop uppercase on primary CTAs everywhere. Keep uppercase only on small labels where the role IS "this is a tag/category/status" (e.g. SalonCard status pill, footer legal). Reduce the 20 tracking values to 2.
