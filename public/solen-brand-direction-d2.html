The 4-tone system

Each color has ONE role. Mixing roles = visual noise. Grok: "one strong warm primary, a softer secondary for hierarchy, muted sage for wellness moments."

Primary clay Main CTA, "Glow" highlight, logo dot, primary action everywhere
#C45C38
Amber Secondary emphasis. Stars in ratings, "See all →" links, hover-fade between primary and body
#D4A373
Deep brown Supporting dark — premium banners (the strip at top), dialog headers, button hover state
#3F2A22
Sage Wellness whisper — Spa & Wellness vertical, "Spa-Day" badge, calm moments only
#5E6B4E
Badge clay Higher-sat version of primary, for time-pressure / discount badges with white text
#D96B45
Neutral ink All body text. Warm dark — never pure black
#2C2522

What changed from D

  • Primary clay nudged from #C15E45 → #C45C38 (slightly more orange, less red)
  • Added amber #D4A373 as secondary emphasis (stars + see-all links — D had no secondary layer)
  • Supporting dark deepened #6B4633 → #3F2A22 (now usable as a "premium surface" bg)
  • Sage #5E6B4E kept — same wellness accent for Spa vertical
  • Promo banner moved from primary to deep brown (more serious, less shouty)
  • Vertical categories now use TINTS of the main palette instead of 4 distinct hues — cohesion ↑
