What changed: the first row of real salon cards, the one already on the page today, gets wider. Nothing invented, no stock photo, no new card. The same salons, the same photos, just bigger, so they carry more of the screen. The row of category buttons above it also loses a little of its own padding, so the cards start slightly higher too.
What this costs, and needs your call: that card size was a decision you already made in July, choosing this exact width over a bigger one on purpose. Making it bigger again means fewer cards visible per swipe, one full card plus a smaller peek of the next instead of a bigger peek. It is a real trade, not a free win, which is why it is shown here rather than shipped.
Both panels are the same live route, not a redraw. The percentage gain above is arithmetic from the card's own real width and photo ratio, not a fresh screen measurement, the shared preview browser this session is using was busy navigating itself elsewhere while this was built, so a live screen-level reading could not be pinned down honestly.
