The cron fix is the one I like most

Because it deletes a gate instead of adding one.

Six crons could report a green run on a night every Stripe charge failed. I built a hook for it. Then the reviewer proved the hook was useless: it looked for a shape that never occurs in our code, and missed the one that does.

The real fix was one line. CronRunResult.errors allowed string[] | number, and the number form was silently dropped. Nothing in the fleet actually used it, so removing | number broke nothing and tsc came back clean. Now it is a build error, forever.

A type error is a gate that can never misfire.
