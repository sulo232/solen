What changed: right now, close to half the text you can see on this page is bold: the "Salons in Basel" heading, the small "Basel" label above it, all four category buttons (even the three you have not tapped), and the star rating on the first salon card. When that much is bold, bold stops meaning anything, it just reads busy. This test makes that same text a touch lighter (medium instead of semibold) everywhere on the screen. The sizes stay exactly the same, so you can still tell the heading from a button from a rating, that job just moves from weight to size and position, which is already how the page is laid out.
What this does not fix: two other things are still off on this screen and this change cannot touch them, because they are about SIZE, not weight. The heading is still only 25px (the floor is 28px), and it is only 1.79 times the body text size (the floor is 1.8 times, a difference of one hundredth). Those need a size fix, not a weight fix. This test does not touch the photos either, and it does not need to: measured fresh, the photo on this page already covers 41% of the first screen, comfortably past the third-of-the-screen floor.
A different, smaller fix for this exact page already exists (floor-fix-city-page): it only lightens the three category buttons you are not standing on, and separately grows the heading to 28px, which clears both the size floors this file leaves untouched. This file is the other approach: a blanket "make everything bold a bit lighter" pass, which is a bigger percentage swing (down to 5.88%) but a cruder tool, since it also lightens the "Basel" label and the star rating that the other fix leaves alone.
Both panels are the same live route, not a redraw. I was handed 54.55% weight and 0% imagery as the starting numbers for this page; measuring it myself, twice, live, I get 47.06% and 41.48%. Both readings agree the weight floor fails badly and the photo floor already passes, so the fix below still targets the real problem, but the exact number I was given for imagery does not match what the page actually renders once its salon list finishes loading, and I am not building on a number I could not reproduce.
