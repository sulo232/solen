DS-6

Blue gets a hover step

Blue stays sparse (small clickable bits only, unchanged). But interactive blue needs a pressed/hover colour: s-accent-deep #1E54B7, one ramp step darker. Hover the links.

DS-7

Card grammar: group → rank → de-label → icon row

"Label: value" pairs are a spreadsheet, not a card. Group related facts, rank by importance, let the UI imply the labels, fold details into one icon row. Labels survive ONLY where genuinely ambiguous.

Content resilience
