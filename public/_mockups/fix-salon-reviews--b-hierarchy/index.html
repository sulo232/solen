Reviews page, hierarchy fix

This screen already has a real anchor: the page title. Nothing else on the page respects it. Seven different sizes are crammed together right below it, so nothing reads as more or less important than anything else.

The fix does not add anything and does not move anything. It just decides: one thing is biggest, one thing is second, everything else recedes to one size.

Before
The live reviews page, untouched. Avatar letters, names, dates, labels and the review text all sit at slightly different sizes with no reason for any of them to differ.
live, unedited
After
Same live page. The title stays the biggest thing. The star rating stays the second-biggest thing. Every other piece of text, names, dates, the review itself, drops to one shared size.
live, fix applied

THE THREE RANKS APPLIED

AaBiggest, 30px. The page title. Was already this size, already the anchor, left alone.
AaSecond, 20px. The average rating number. The one other real number on the screen.
AaRecedes, 14px. Everything else: names, avatar letters, dates, labels, the review text, the write-review button.
Both boxes above are the real page loading right now, not a drawing. Before is exactly what ships today. After has one rule applied by a script after the real page loads: any text that was not already the anchor or the rating number is set to 14px. Nothing is added, removed, or moved.
What this fix does not touch: there is still no photo on this page, so the imagery floor stays failed either way. That needs real content added, a different kind of fix from re-sizing text, and is out of scope for this file on purpose.
