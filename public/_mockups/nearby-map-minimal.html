What changed

  • Reference-matched palette. Pixel-sampled from the owner's screenshots: water #CBE3FC, parks #CFF2D0, land #E8EAEA, near-white roads #F8F8F8.
  • Calm, not cluttered. Major roads only, minimal labels, and overlapping salons cluster into a count badge instead of a pile of dots.
  • Rating + review count in the marker. Real values (4.13 to 4.81, 7 to 25 reviews). Overlapping salons merge into a labelled "10 Salons" badge, so no bare mystery circle.
  • No "Karte öffnen". The whole card taps through, so the button is removed. Only the frosted count chip stays.
  • Live map. Rendered with mapbox-gl (already a dependency), so this is exactly what ships , not a picture.
