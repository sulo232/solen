Seven Airbnb learnings, measured on this page

390×844, live /de, this session. Before = measured now. After = applied in this Proposed pane.
1
Hairline only where a group ends
Not applicable here: 0 violations found.
The only border+per-row-divider combo in the homepage component set is CategoryStack.tsx, and it is dead code (no import path reaches it from page.tsx). Home's 16 live bordered containers are each an individually-tappable single card (search pill, map teaser, 4 rail cards, 2 Walk-in chips, its CTA), the locked individual-entity-card grammar, not a list.
2
Icon terminals, butt/miter not round
Before: round/round on 160 of 160 stroked lucide iconsAfter: butt/miter
Live DOM read this session, whole /de. Library default (Lucide), never overridden. Applied here to every stroked icon in this Proposed pane: search glyph, section chevrons, card hearts, stars, walk-in arrow.
3
Weight never exceeds 600
Before: 700 on 5 roles in WalkInBand.tsxAfter: 600 max
H2 "Walk-in", the Live badge, the wait-time number, the salon name and the CTA all shipped weight 700 (font-bold). Rest of the feed already caps at 600 (19.3% of feed text at weight>=600, under the 30% ceiling) — WalkInBand was the one section that broke its own page's convention.
4
One letter-spacing value
Before: 4 distinct values in the feed (normal, -0.18px, -0.14px, -0.4px)After: 2 (normal for meta/subline, -0.01em for names/headings)
WalkInBand's salon name used normal tracking while every other card on this page (SalonCard.tsx) uses -0.01em for the same role — a same-role inconsistency. WalkInBand's price used a bespoke -0.02em nobody else on the page uses; merged into the page's own dominant -0.01em (already used 11 times by every section H2).
5
About three text sizes
Before: 8 distinct sizes in the feedAfter: 7 (12.5px merged into 12px)
The Nearby map badge was the one single-instance size (12.5px) with no shared role — merged into the existing meta-text bucket, the same move already made once on this page (MobileCategoriesRow.tsx's own 13→12px tile-label merge). 7 still exceeds "about three": this page composes ~9 structurally different section types (hero copy, rail cards, a live-status band, a map badge) where Airbnb's reference is one homogeneous settings list, so a further collapse to 3 needs a page-wide type-scale decision beyond one section's fix. Named, not hidden: this is also CLAUDE.md's own NEVER-AGAIN floor 2 (≤4 sizes/screen), which this page fails independently of the Airbnb comparison.
6
Almost no colour, ink glyphs otherwise
Not applicable here: 0 violations found.
Non-neutral colour on this slice: gold star (rating value, universal meaning), green (Walk-in's live wait status, a real-time fact the user must notice, same role as Airbnb's status colour, not decoration). No blue on this slice. Matches Airbnb's own small, role-tied colour budget.
7
Row height fixed regardless of content
Not applicable here: 0 violations found.
Measured 8 rail cards this session: all 250px. 4 RecentlyViewedTiles: all 140px. SalonCard.tsx's Row 3 (address+price) is conditionally rendered when both are null, which could in theory shorten a card, but no card in the live seed data hits that case today.
