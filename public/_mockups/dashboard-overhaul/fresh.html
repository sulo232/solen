Solen Operator Dashboard

The home surface, rebuilt from scratch, three ways

Three genuinely different structures for the operator dashboard home, each grounded in a reference the owner named: Workable (top nav, 3 columns), Uber Eats Manager (a live-ops board with a bottom action dock as the nav) and Linear / Stripe (a labeled sidebar plus one calm column). None of the three reuses the current 64px icon rail or the current single stack of white cards, both structure and navigation paradigm are new per direction. The Solen tokens, fonts and icons stay identical across all three, only the skeleton changes.

D1, Workspace
Workable's real structure: a horizontal top nav bar with labeled text tabs, and a home composed in three columns (salon + status, today, to-dos + live). No left rail anywhere.
