Nail-tech , tier badge

The nail-tech profile shows a skill tier (Junior / Senior / Master). Today each tier gets its own colour chip, but the category-tag law already decided this exact case: a label whose value varies but carries no universal meaning stays neutral, not colour-coded.

Direction A , neutral badge recommended

One neutral chip (bg-s-bg-sunken + ink text) for every tier, like the category tags. The tier word carries the meaning; colour adds nothing and would compete with the real semantic colours (star, success, error).
