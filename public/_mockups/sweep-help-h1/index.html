Help and info pages , H1 title scale

The help / About / blog pages each set their own H1 size (24-48px), none matching the locked Page title scale. Two consistent systems below, each shown on a brand page (About) and a utility page (a help article).

Direction A , one scale everywhere simplest

Every help/info page uses the one locked Page title size (~20px). Dead consistent with the rest of the app's sub-pages; loses the editorial "presence" on the brand pages.

Direction B , two-tier

Brand pages (About, blog, why-Solen) keep a larger editorial hero (~34px); utility pages (help articles, legal) use the Page title size. A documented two-tier system, not three ad-hoc sizes.
