Icons, Steps & Badges

How grey, black, and colour are spent on every glyph, step tracker, and badge. Grounded in Apple / N26 / Beli (Mobbin).

Philosophy: colour is earned, not default. A glyph is monochrome until it earns colour from state, interactivity, or selection. If every icon is tinted, colour stops meaning anything.
A. Icon colour model
Default: monochrome, matches its text
Row glyph = ink (its title). Chevron + meta = grey. Never tinted.

Ink glyph + grey chevron. The chevron is always grey, never tinted. Same rule as Beli / Instagram / Flighty.
Colour overrides, only these four
1. State / meaning
Green = done/paid, red = delete, yellow = rating, pink = saved. The icon IS the message.
2. Tap target IS the icon
Blue, only when the glyph itself is the button (a bare icon-action). Not a decorative icon inside a row.
3. Selection
Ink check (Layer-1 chrome). Solen picks ink over Apple's blue tint for selected staff/options.
4. Over a photo
Frosted white glass (FROST_GLASS). A glyph on imagery is never bare-tinted.
