The X-ray — how Pinterest does search + filters

From live Pinterest iOS screens (Mobbin). The throughline: one filter row + a sliders button, and a search that opens suggestions on focus.

SEARCH (RESTING)

One prominent field

  • Rounded, full-width, grey fill
  • Search icon left, mic right
  • Tapping it → suggestions view
SEARCH (FOCUSED)

Autocomplete list

  • Top / People / Boards segment tabs
  • Text suggestions, typed part bold, rest grey
  • Recent searches with a clock icon
FILTERS

One pill row + sliders

  • Single horizontal-scroll pill row
  • Some pills are toggles, some have a ▾ dropdown
  • A round sliders icon opens the full filter sheet (dot = active filters)
  • Never two stacked pill rows
DEEP FILTERS

Bottom sheet

  • Sliders icon → sheet (range sliders, toggles)
  • "Apply" CTA at the bottom
  • Keeps the main view clean
