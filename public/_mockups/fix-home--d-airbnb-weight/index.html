What changed: right now, more than a third of the text on the home page's first screen is bold. When most things are bold, bold stops meaning anything, it just reads busy. This test makes that same text a touch lighter (medium instead of semibold) everywhere on the screen: the "Top auf Solen" and "Top Coiffeur" titles, the salon names, the prices, and the star ratings. The size of everything stays exactly the same, so you can still tell what is a title and what is a price, that job just moves from weight to size and position, which is already how the layout is built.
What this does not fix: two other things are still off on this screen and this change cannot touch them, because they are about SIZE, not weight: the biggest text on the page is still only 18px (we want at least 28px so there is a real headline-sized moment), and the size difference between the biggest and smallest text is still smaller than it should be. Those need a separate fix. This test also does not add any photo, the page's photo coverage is unchanged.
Both panels are the same live route, not a redraw. The lightened weight is applied here as a test overlay on Tailwind's shared "semibold" utility, which is used across the whole product, so shipping it for real would need it scoped to just the home page first.
