Design language v2

The new system on one screen, for sign-off on the language itself. White-first surfaces, blue used generously on anything you can touch, one ink commit anchor per screen, and deep confident success color. Everything below animates on load so you can feel the motion.

What v2 changes

  • Blue = interactivity. Used generously on links, "see all", active tabs, and tappable rows — kept off body text so it never vibrates.
  • One ink commit button per screen (#0A0A0A) is the single strong anchor; all other actions lean blue.
  • White-first, cooler surfaces. Warm cream is dropped; only a cool grey #F4F4F5 fills where needed. No dark surfaces anywhere.
  • Deep, confident success. Dark-green #15803D disc + white checkmark instead of pale-green tints.
  • Visible motion. Staggered rise-in on load, success ring pulse + disc spring-pop + check stroke-draw, card hover lift, blue link hover, press scale.
