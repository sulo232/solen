What changed - v2

All three empty states now share one anatomy (cool-grey soft circle → calm ink-3 icon → Inter Tight title → one muted line → ink CTA or blue link), instead of three ad-hoc treatments. The retired warm cream and the old green/blue tile are gone - surfaces are white-first with a single cool grey #F4F4F5.

The Live Queue is the biggest shift: the dark display is dropped entirely for a light surface that matches the rest of the app, so an empty queue reads as intentional rather than broken. Blue now carries interactivity (back link, header icon-buttons, the "Explore looks" link), while each screen keeps exactly one ink commit button ("Add walk-in" / "Get started"). An on-load fade-up with a gentle stagger plays on entrance and loops on each AFTER frame so the motion is visible.
