This page had no anchor

The barbershop page has no single piece of text that clearly says "this is what you're looking at." Its biggest word right now, 20px, is a small repeated status label inside the walk-in row, not a real heading. This mockup gives the page one real anchor, at your house size of 30px, and shrinks the two things that were accidentally competing with it.

Both screens below are the real, running page. Three sizes change. Nothing moves, nothing is added or removed, nothing changes color. Every number in a badge is computed by this page reading the real one live, not typed in by hand.

With one real anchor

The first rail's own heading becomes the page's one big anchor. The repeated availability word and the odd-sized map button both step down to match everything else.

measuring...
What actually changes. Three things, and only these three. The first rail's heading grows from 18px to 30px, your house anchor size. The walk-in row's own availability word, shown three times, shrinks from 20px bold to 14px medium, it was the biggest thing on screen by accident, not by decision. The floating map-toggle button merges from an odd 13.5px into the same 14px everything else on the screen already uses. Every other card, name, price, and row stays exactly where it is and exactly the size it is today.
Why this heading and not something new. This page had no headline of its own, just a search bar and filter row above the first rail. Rather than invent a new heading that isn't wired to anything, this uses the heading the page already renders and already fetches: the name of the exact category you're looking at. It is the first real content a visitor reaches, and it says what the screen is.
What this does and does not fix. It clears the three floors this mechanism was built for: the page now has a real 28px-or-bigger anchor, that anchor is more than 1.8 times the screen's typical text, and the number of different text sizes crowded together drops from 5 to 4, with the densest cluster down from 5 to 3. It does not fix the two floors below, because fixing them needs a different kind of change.

Two floors this file leaves for you, with real numbers

Too much bold text (45.24% before, 30% is the ceiling): shrinking the availability word alone brings it down to 38.10%, still over. The rest of the bold text is either the salon card's name and price (locked sitewide, on purpose) or the rail section titles (shared with the home page and the other two category pages). Un-bolding either one only on this page would fix this screen and quietly break the others the moment it shipped.

Not enough photography (21.59% before and after, 33% is the floor): this mechanism touches text size and weight only, zero pixels of photography change. Raising this needs more real salon content shown higher up the page, which is a different fix than the one this file makes.

What this file does not touch. It does not resize the salon cards, the rail section titles, or the walk-in row's own heading (both stay exactly 18px, now correctly the page's second tier, under the new 30px anchor). It does not add, remove, or reorder a single card, rail, or section. It does not restore anything from the graveyard: no category pill, no dashboard panel, no makeup or waxing surface. The only thing that changed is three font sizes.
