The booking-flow primitive. Calendar grid + time-slot list, composed for the booking wizard's "pick a date + pick a time" step. v1 ships single-date and date-and-time. Range picker (vacation blocks) defers to v2. Localized to DE-CH (Monday-first week). Native input banned per spec — too inconsistent across iOS / Android / desktop.

Anti-patterns §F.5.7 · banned

Anti-patterns

What Solen date pickers do not do.

Banned
Native <input type="date" />
Native pickers vary wildly across iOS / Android / desktop. We lose visual control over the most user-facing primitive in the booking flow.
Banned
Year-month picker as scrolling wheel
iOS-specific UX, doesn't translate to desktop. Use chevron month-nav. v2 may add a year-picker overlay.
Banned
Showing all 24 hours flat
Group by day-period (Vormittag / Nachmittag / Abend). Reduces visual load + matches mental model.
Banned
No disabled-date support
Booking flow MUST disable past dates + salon-closed days. Default minDate=today.
Banned
Range picker in v1
Single date only. Range deferred to v2 (used for B2B vacation blocks).
Banned
Italic anywhere
Per V2-D15. Days, time slots, group labels — all upright Avant Garde Gothic.
