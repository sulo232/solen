P3 — frontend polish mockups for approval

Five owner-dashboard screens that still ship a desktop layout on mobile: settings panels rendered as multi-column grids, a horizontal-scroll heatmap, a service-edit modal with a colour bug, and a queue card that runs off the right edge. Each phone below rebuilds the affected screen in the approved skin (white page, 16px hairline cards, ink primary CTA, light-blue active = #EAEFFE bg + #276EF1 text, bare lucide icons), so the fix can be approved before any app code is touched. The English note under each frame states exactly what it corrects. Salon: „Cuts & Culture".
