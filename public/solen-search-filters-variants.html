Features (icons) vs Filters — 4 layouts + the shared sheet

You were right: round icons = features the salon HAS (walk-in, parking, card pay...) — browseable, like your homepage tiles. Offen jetzt / Sofort / Top are filters (toggle them to narrow results). Researched Airbnb, Uber Eats, Vivino, Beli, eBay on Mobbin — they all split it the same way. The only choice is how the two layers sit on the page. Pick one.

Airbnb: icon row + sliders button to a sheet Uber Eats: icon row + inline filter chips Vivino / Beli / eBay: one Filter button to a full sheet LIVE = works with today's data NEEDS DATA = new DB column first
