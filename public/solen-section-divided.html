Recommendation

Option 3 (Hybrid). Section bg follows section JOB, not aesthetic.

The Hims pattern works because each warm shade does a job — pale yellow = "scientific," peach = "personal," brown = "premium," dark = "trust." It's not random rhythm. For Solen, the same logic works with a mixed palette IF each color has a job:

  • Cream (#FFF8F0) → emotional/browsing sections (hero, categories, "explore"). Warmth = "this is self-care."
  • White (#FFFFFF) → transactional sections (search, listings, checkout flow). Clean = "decision time."
  • Cobalt-tint (#E2E8FA) → "your stuff" / brand-owned content (recently viewed, favorites, account). Says "Solen-family."
  • Cream-2 (#FAF4E8) → testimonials, social proof, community. Different warm to break monotone.
  • Dark navy (#0B1430) → trust signals (stats, guarantees, security). Punctuation, used sparingly.
  • Cobalt (#133EEB) → conversion moments (final CTA, app download). Full brand assertion.

The thinking from first principles: if a section's background is the SAME as the section above it, you're saying "this is the same kind of thing." If it differs, you're saying "this is a different kind of thing." Hims got rhythm by treating bg-color as INFORMATION — match the bg to the section's purpose, and the page reads like a well-paced argument instead of a wall of text. Pure-warm (Hims-clone) loses the cobalt brand. Pure-cool loses the wellness warmth. Hybrid keeps both — at the cost of needing real design rules about what color goes where.

If you ONLY want one tone (simpler to maintain): pick option 1 (warm) — wellness category bias is strong enough that warm + cobalt accents is the easier sell than cool + cobalt. Cool/option 2 only wins if Solen wants to compete on "Swiss tech utility" instead of "Swiss wellness."
