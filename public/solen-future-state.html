What changes in B vs A

  • Section bgs: 3 colors (white / warm ivory / sea-glass) → 1 color (white only)
  • Section dividers: color change → thin 1px hairline + bigger vertical breath
  • Logo dot: orange → teal (2-color brand identity in 1 mark)
  • Eyebrow dots: grey/none → teal — present on every section header
  • Heart outline: ink → teal — present on every salon card
  • Arrow buttons: teal (unchanged from current — already shipped)
  • BentoBusiness anchor: teal (unchanged — still the big dark moment)
  • Orange CTAs: unchanged — still the 10% click signal

Trade: B is more confident + premium (Aesop pattern) but riskier — needs strong typography rhythm + good content variety to differentiate sections without color help. A is safer + more visually segmented but has the "color-tint divider" feel you're trying to escape. Try B for a few minutes; if it feels too austere, we have the data to tune mid-state (keep ONE tint, ditch the others, or use ultra-pale 99% white-leaning tints that read almost-white but give micro-rhythm).
