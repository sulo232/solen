About the built in animate feature

It exists, but it cannot make this turn. That feature rigs a humanoid skeleton and plays a canned body clip from a 678 action library, things like walk, idle, wave, dance. Our subject is a person fused to a chair, which is not a biped, and a search of the library for turn, rotate or spin returned nothing usable. The spin here comes from a camera moving around the object, which is also why the last frame lands exactly on the first. A body animation could still be useful later for a different icon, for example a stylist gesture.

What is honestly still rough

  • The mesh is reconstructed from one image, so the back of the chair is guessed and reads softer than the front. Feeding 2 to 4 views would fix it.
  • No Safari file yet, so today this would only play in Chrome and Firefox.
  • This is one icon. A set needs the same treatment for the other categories, and they should share a palette and a camera height.
  • Nothing is wired into any Solen screen. That is a separate step and it goes through the normal mockup approval first.
