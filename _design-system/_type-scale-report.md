## Tunables

- `ALLOWED_PX` (top of script): the locked type scale. Extend here only with a citation to a LOCKFILE / CLAUDE.md row, never a guessed value.
- `TEXT_SIZE_RE`: the detection regex. Matches `text-[Npx]`, `text-[N.Npx]`, `text-[Nrem]`, `text-[N.Nrem]`; does not match `text-[clamp(...)]` by design.
- Scan roots: `app/`, `components/`, `components-legacy/`, `.tsx` only, same as the sibling detectors.
